【项目概述】本作品是一款面向企业级云原生生态的高性能动态 API 网关。依托 Go 官方标准库 httputil.ReverseProxy 提供核心转发，自研重构外壳与扩展机制，专注于解决海量 QPS 下的长尾延迟与 GC 内存抖动问题。
【核心硬核优化点（资深底蕴）】动态路由完全无锁化：利用 sync/atomic 机制结合 Copy-On-Write 思想，实现 100% Lock-Free 的路由查找，更新期间零读请求阻塞。链式插件全链路零内存分配：引入严苛的 sync.Pool 内存池化管理 GatewayContext，将高并发下多插件流转的单次请求内存分配次数降至 0 次（Zero-Allocation）。网络 IO 参数压榨：克隆默认 http.Transport 并按代理场景调参（MaxIdleConns=10000、MaxIdleConnsPerHost=2000、IdleConnTimeout=90s，包级单例热加载复用），降低高并发下反复建连的握手开销与 TIME_WAIT 堆积。
【基准压测数据（本机实测，原始输出见 doc/bench-report.md）】路由匹配（1000 条路由、并行 16 线程）：4.28–17.23 ns/op、0 B/op、0 allocs/op（优化前 29.55 ns/op / 56 B / 3 allocs）。网关完整请求路径（上下文池 → 路由 → 插件 → 本地处理器，不含网络）：70.84–77.22 ns/op、0 allocs/op。动态路由写路径为 COW 整表复制：表长 10 / 100 / 1000 条时 1.09 / 4.11 / 25.33 µs，定位「低频写、高频读」。端到端链路连续 11.2 小时：推流 26.9 GB、dropped=0、RTP 15,880,248 包零丢弃。未复跑的 QPS / P99 数字已删除，真实 HTTP 吞吐请按报告第 7 节用 wrk/hey 在目标机器复测。
